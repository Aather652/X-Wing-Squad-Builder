# X-Wing Squad Builder

A React-based squad builder for X-Wing miniatures with editable ship points, custom ship creation, squad management, and browser local storage persistence.

## Run locally

1. Open a terminal in the project folder:
   ```powershell
   cd "C:\Users\Ayden\Desktop\X Wing Squad Builder"
   ```
2. Install dependencies:
   ```powershell
   npm install
   ```
3. Start the development server:
   ```powershell
   npm run dev
   ```
4. Or run both install and dev in one step:
   ```powershell
   npm start
   ```
5. Open the local URL shown in the terminal.

## VS Code task

Use the VS Code task `Install and Start` to install dependencies and launch the dev server in one command.
